# Workflow: meetings

Pre-meeting briefings and post-meeting decision capture.

## Commands

| Command | What it does |
|---|---|
| `/meeting-prep` | Briefing for today's meetings with attendee dossiers |
| `/meeting-debrief` | Capture decisions, actions, and distribute summary |

## Example session

```
You: /meeting-prep
Claude: [reads calendar, identifies next meeting]
Claude: Meeting: "Cards Strategy Review" at 14:00
        Attendees: [dossiers with recent email context]
        Topics to prepare: [based on recent correspondence]
```
