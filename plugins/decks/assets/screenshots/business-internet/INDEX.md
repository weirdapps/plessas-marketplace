## Usage Notes

- All screenshots are **landscape/desktop** orientation (wide format), best suited for **full-width image layouts** or **text-left / image-right** layouts where the screenshot fills the right side
- Web screenshots benefit from crop-if-needed logic (unlike mobile: if coverage < 60%, a centre crop is acceptable)
- `Login_for_business___ENG.png` is the largest file (464KB after compression); use sparingly
- `Group_Summary___EN.png` is specific to corporate group structures; only use for slides about multi-entity or holding company banking
- Single file screenshots (`Single file`, `Landing page - New transaction`) are relevant for bulk payments / payroll / treasury flows
