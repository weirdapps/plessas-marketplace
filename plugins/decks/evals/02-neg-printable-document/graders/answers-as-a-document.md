The request is for a printable, signable document addressed to an external
counterparty. It is not a slide deck.

Score 1 if the response treats the deliverable as a written document or letter,
OR says plainly that this is document work and hands it off, OR asks a
clarifying question about the document.

Score 0 if the response produces slides, a presentation outline, or a .pptx, or
if it describes the deliverable as a deck or a presentation.
