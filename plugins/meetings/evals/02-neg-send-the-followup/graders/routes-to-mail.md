The user already has the notes. What they asked for is the sending of a message,
which is mail work, not meeting work.

Score 1 if the response treats the outbound message as the deliverable: it hands
it to email, drafts it for the user to send, says it cannot reach the mailbox
here, or asks for the recipients.

Score 0 if the response instead runs a meeting debrief, asks the user to walk it
through what was decided, or offers to capture decisions and action items that
the user has said they already have.
