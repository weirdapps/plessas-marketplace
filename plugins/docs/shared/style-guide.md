# NBG Document Style Guide

Default conventions for Word documents (`.docx`) generated by the `docs` plugin — `/docs-create`, `/docs-letter`, `/docs-memo` — and for direct `document-skills:docx` calls in NBG contexts.

---

## Defaults

| Element | Setting |
|---|---|
| **Font** | Aptos (all text — body, headings, header labels, footers) |
| **Body color** | `#404040` |
| **Heading / header-label color** | `#007B85` (NBG Teal — primary brand color) |
| **Body size** | 11pt |
| **Heading size** | 14pt |
| **Margins** | 2.54 cm all sides |
| **Page numbers** | Bottom centre |

---

## NBG Teal — the primary brand color

In every artifact (.docx, .pptx, .html, RTF, SVG/PNG) use **NBG Teal `#007B85`** wherever previous specs referenced NBG Green `#006141`. Green is retired across all media.

Earlier `docs` plugin drafts used `#003841` (NBG Dark Teal) for headings. The current default is `#007B85` (NBG Teal primary) so docx output matches the brand color used in decks and email.

Adjacent teals stay valid:
- `#003841` (Dark Teal) — still valid for HTML table footers/totals and for certain accent uses; do NOT bulk-rewrite `#003841` everywhere
- `#5A5F5A` (Caption Grey) — captions, owner subtitles, table notes

Only the green → teal swap is universal.

---

## Verification

After generating any docx, inspect the XML:
- Heading runs (`<w:rPr><w:color w:val="..."/></w:rPr>`) should read `007B85` — not `003841` or `006141`
- Body runs should be `404040`
- Font (`<w:rFonts w:ascii="Aptos" .../>`) should be `Aptos` (not Calibri or Cambria)

---

## No em-dashes

Never use em-dashes (`—` or `--`) in document body, headings, or footnotes. Replace with comma, colon, semicolon, or full stop based on context. Same restraint for en-dashes used parenthetically; date/number ranges with en-dash are fine (`2024-2025`).

Em-dashes read as AI-generated and signal Claude authorship — unacceptable in executive documents.

---

## Never invent NBG names

Do not guess or fabricate names of NBG executives, division heads, or organisational roles. If a name isn't already known from your personal shared memory, email history, or the current conversation, **ASK** — never guess.

Acceptable framings when name is unknown: `NBG [Division] leadership`, `the relevant [Division] head`, `the NBG [Division] team`.

---

## File naming

Generated docx files use the convention `YYYYMMDDHHMM_descriptive_name.docx` (Athens timezone). Never append `_v1`, `_v2`, `_final`, `_revised` suffixes — the timestamp IS the version. Fresh timestamp on each save makes iterations sortable and unambiguous.

---

## Per-command defaults

The three commands in this plugin (`/docs-create`, `/docs-memo`, `/docs-letter`) inherit these defaults via the plugin's prompt patterns. If you generate a docx outside the plugin (direct `document-skills:docx` call), manually apply these defaults — the skill itself ships Anthropic defaults (Calibri/Cambria, black) which need to be overridden for NBG output.
